<h2>📌 About the game</h2>
<p>
  <b>ZombCity Survival</b> is a 2D pixel-art game made in Unity Engine.
  The main theme is a zombie apocalypse where you, the survivor, has to encounter waves of
  zombies making as much score possible.
</p>



<h2>🛠️ Technologies Used</h2>
<ul>
  <li><b>Unity</b> – Game engine</li>
  <li><b>C#</b> – Programming language </li>

</ul>
